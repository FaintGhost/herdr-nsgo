# tmux 与 Zellij 会话接入

## 行为约定

在「新建会话」选好实例与运行机器后，用户可以打开多路复用器列表。切换 tmux 或 Zellij、刷新和关闭只读取会话。已有会话必须显式点选才接入。空列表、工具未安装、主机不可达分别显示原因。运行中和可恢复的 Zellij 会话按主机报告的状态显示。

接入后打开 Herdr 的终端视图。返回应用首页保留远端客户端，重新接入时优先复用同一主机上仍在运行的客户端。分离仅退出当前客户端，远端会话中的程序继续运行。新建使用主机上的工作目录和所填名称。控制面板提供窗口或标签导航、新窗口或标签、分屏和分离。

## 依据与验证

会话生命周期及默认按键参考公开的 [tmux 使用说明](https://getmoshi.app/docs/tmux) 和 [Zellij 使用说明](https://getmoshi.app/docs/zellij)。命令参数、空列表退出状态和分离后的持久性通过隔离主机上的 CLI 验证。Go 实现只依赖公开 CLI、Herdr 的 `machine.exec`、`terminal.run` 和现有 NSGo 终端组件。
